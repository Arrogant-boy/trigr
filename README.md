- 🧽 PowerWash Simulator 2
- 🍂 Leaf It Alone

## 🚀 Installation
1. Télécharge `Trigr-Player-x.x.x.exe` et le pack de ton jeu
2. Lance le Player, accepte la licence, puis clique sur **Importer…** et choisis le pack
3. Dans **Mod du jeu**, indique le dossier du jeu : le mod s'installe tout seul
4. Dans **✏️ Personnaliser**, choisis tes cadeaux, puis connecte ton live

⚠️ Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » :
clique sur **Informations complémentaires** → **Exécuter quand même**.

Le Player te prévient tout seul quand une nouvelle version sort.
